本机机器码

将此机器码发给供应商即可获取对应许可证（部署在客户机上时，客户应发送其自身机器码）。

说明：机器码 = SHA256(主机名|平台|系统版本|首块网卡MAC)，换机或改主机名将导致校验失败。

使用流程

  1. 取机器码：在目标部署服务器上打开本程序「本机机器码」，复制机器码发给供应商。
  2. 生成：供应商在本程序「生成许可证」粘贴机器码+有效期，生成许可证字符串。
  3. 激活：客户在「激活」选择服务器 instance 目录并粘贴许可证，写入 license.key，系统即转为已授权（无需重启）。
  4. 校验/吊销：随时在「校验」查看有效期与机器码匹配；在「激活」可吊销清除。

许可证采用 HMAC-SHA256 签名，绑定机器码 + 有效期；篡改或换机均会校验失败。
